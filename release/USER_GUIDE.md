# User Guide

## Introduction
MT5 Strategy Console allows you to connect to an active MetaTrader 5 terminal, define technical strategies, run historical backtests, monitor the market live, and observe external EA activity (Bot Observer).

**THE APPLICATION DOES NOT PLACE TRADES.**

## Workflow
1. Install MetaTrader 5 on your system.
2. Log into your MT5 demo or real account.
3. Start MT5.
4. Open MT5 Strategy Console.
5. Ensure the Dashboard shows **MT5: CONNECTED**.
6. Create your strategy in the **Strategies** tab and save it.
7. Perform a Backtest in the **Backtest** tab using your Strategy and a downloaded CSV of historical data.
8. Start Live Monitoring in the **Monitor** tab.
9. Receive desktop alerts and view them in the **Journal**.
10. Make trading decisions manually.
11. View history and export data from the **Data Export** tab.

## Bot Observer
The **Bot Observer** is a special feature designed to monitor an external EA running on XAUUSD. It runs passively and records observable events (new positions, orders, deals) to a CSV file.
